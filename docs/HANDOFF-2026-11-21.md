## 1. 这是什么

2026 飞猪 × 阿里云百炼 AI 旅行创新大赛参赛项目，团队「未竟工作室」，官方赛道：目的地探索。
产品：**给「带爸妈出游」的人用的半日步行路线工具**。用户把爸妈的体力说出来，系统用真实数据排一条走得到的路线，并告诉他走不到时是哪一条限制卡住了。

### 这座城能不能进预设——六道门槛，逐条看输出

| 门槛 | 看哪里 | 不合格怎么办 |
|---|---|---|
| G1 起点被正确核实 | `report.start.name` / `address` | 若拿到「停车场/入口/××店」，换更具体的 `START=` 重跑（多一次冷跑）。青岛拿到的就是「劈柴院·江宁会馆」，可用 |
| G2 密度够 | `report.routableCount`、A 档站数 | `<3` 站 → 该城候选太散，**不进预设**，如实记录 |
| G3 默认路线不至于走崩 | A 档 `maxLegMeters` | `>2500` 米说明最短名单里有超远段，考虑换起点或放弃 |
| G4 **核心承诺** | C1「单段 ≤900 米」能不能排出 ≥3 站 | 排不出＝这城做不到「每段都走得动还逛得够」；杭州、苏州都做不到，只有青岛做得到 |
| G5 营业时间窗口 | 拒绝清单里 `确认冲突` 的条数 | 大半候选是夜间营业（像青岛台东小吃街 19:00-23:00）→ 下午半天会大面积失效 |
| G6 厕所覆盖 | `report.toilets.anchorsWithoutToilet` | 一条线上多数站 800 米内没标注是**正常的**（青岛 5 个锚点只有 1 个有），别当作 bug，也别拿去当卖点 |

**行政区清单漏写的后果**（容易踩）：漏某个区名不会让核验报错，只会让「同名异地」这道护栏变松（`extractDistrict` 返回 null → 比对结果变成「无法判断」而不是「不一致」）。跑完后看拒绝清单里有没有「行政区冲突」，一条都没有且候选地址里有你没写进去的区名，就补上再跑一次。

**排不出路线是正确行为，不是故障。** 不要为了「让这城出路线」去放宽 8 公里直线门槛、缩短停留模拟值或塞进未经核验的点——那是这个作品唯一的成绩单。

## 7. 本机会咬人的坑

1. **所有缓存、计数器、事实集都在进程内存里。** 重启 `next start` = 下次核验全冷跑（每城 28–36 次调用）。**先写完代码、build 完、重启完，再花钱暖**；别边改边暖。
2. **改白名单不 build 就没生效**——`SUPPORTED_CITIES` 是编译期常量。曾经因为 start 了旧构建白花 60 次调用。
3. **Windows 上两个进程能同时占 :3000**，请求由先绑定的那个服务。杀不干净就会拿到旧代码/旧 key。`netstat -ano | grep LISTENING | grep ":3000"` 必须只剩一个 PID。后台任务包装器被杀死时 node 进程常常还活着（本次实测 PID 会残留）。
4. **管道吞退出码**：`git ... | tail -5` 的成功是 `tail` 的成功。看输出里有没有 `fatal:`，或用 `${PIPESTATUS[0]}`。
5. **`curl -d` 会把中文弄坏**，测接口用 `node -e "fetch(...)"`。
6. **推 GitHub**：代理在 Clash `127.0.0.1:7897`（http）与 v2rayN `10808`（socks5）之间轮流死，先 `netstat` 量哪个活着。凭证必须每次临时覆盖，**且要先用 `-c credential.helper=` 清空**，漏了清空会被 Windows 凭证管理器的错号先答话，报 `denied to hxrhsq`（403）：
   ```bash
   git -c http.proxy=http://127.0.0.1:7897 -c credential.helper= \
       -c credential.helper='!f() { echo username=mckinstryhancher688-pixel; echo password=$(gh auth token --user mckinstryhancher688-pixel); }; f' \
       push origin feat/family-mode
   ```
   核对远端用 `git ls-remote origin refs/heads/feat/family-mode`，同样要带这套 `-c` 参数。
7. 内存紧张时 `next build` 会死于 `os error 1450` / exit 3221226505，先腾内存。`NEXT_BUILD_WORKERS` 是**不存在**的变量。

## 8. 付费纪律（用户非常在意）

- **闸门是我们在进程里自己设的**：place 40 次/小时、walking 200 次/小时；另有日上限 place 90 次、walking 4000 次（低于官方 5000 次/天）。重启会把这些计数清零，**但高德自己的日配额不会跟着你重启**——别把重启当刷额度。
- **一小时能暖几城：安全口径是两城。** 实测每城冷跑：杭州 11 place + 25 walking、苏州 12 + 16、青岛 11 + 25。
  三城合计 **34 place / 66 walking**——数字上还没顶穿 40/80，但**只剩 6 place 的余量**：任何一次失败重跑、
  换起点重跑（拙政园那次实测 +1 / +4）、或一次无障碍厕所补查（+1 place），就会撞闸。所以按小时分两批，
  第三城留到下一个小时。这不是从上限算出来的硬规则，是**留重试余量的工程判断**。
- 花钱之前先一次性交预算方案，得到一句确认再花；不要边改代码边反复冷跑。
- 百炼侧：一次「我到了」≈1 回合、约 1.7k 输入 / 40–140 输出 token、3.6–5.5 秒（已调优口径）。地图平移/缩放/选点**不得**触发百炼调用。
